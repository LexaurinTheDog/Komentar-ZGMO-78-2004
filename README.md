# Komentář k zákonu č. 78/2004 Sb., o nakládání s geneticky modifikovanými organismy a genetickými produkty

Otevřený komentář k zákonu o nakládání s geneticky modifikovanými organismy a genetickými produkty — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; uzavřené nakládání, uvádění do životního prostředí a na trh, dovoz, vývoz a tranzit, registry, výkon státní správy, opatření k nápravě a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2004-00078_2025-07-01`.
